Privacy Policy

FHMIS Secure Backup

Last updated: November 8, 2026

1. Purpose

FHMIS Secure Backup is being configured to protect authorized files and development records associated with the Forest Harvest Management Information System.

2. Google Drive Access

The planned integration uses Google Drive authorization granted by the account owner. The intended permission is limited to files created or managed by the backup application.

This access will be used to upload, retrieve, manage, and delete authorized backup files when necessary for backup and recovery.

3. Data Storage and Security

Backup files are intended to be encrypted before upload using a dedicated backup tool. Encryption credentials will be maintained separately from Google Drive.

The backup integration is not yet active. Security and recovery testing will be completed before operational use.

4. Data Sharing

Google Drive data accessed through this integration will not be sold, used for advertising, or shared with unauthorized third parties.

Google processes stored files as the selected cloud storage provider.

5. Data Retention and Deletion

Backup retention settings will be defined before operational use. The authorized account owner can manage or delete stored backups and revoke application access through their Google Account.

6. Access Control

Backup access is intended for authorized administrators only. Production credentials, encryption passwords, and private keys must not be published on this website.

7. Changes to this Policy

This policy will be updated if the backup workflow, requested permissions, or data handling practices change.

8. Contact

For privacy-related questions, contact the application administrator using the support email provided on the Google OAuth consent screen.
