About FHMIS Secure Backup

FHMIS Secure Backup is a backup solution being configured to protect authorized development files and system recovery information for the Forest Harvest Management Information System.

Google Drive Integration

The planned backup workflow uses Google Drive with authorization from the account owner. Backup archives will be encrypted before upload.

Google Drive access will be used for backup storage and recovery operations.
